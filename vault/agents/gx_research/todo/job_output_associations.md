# Component - Job Output Associations

How a Job's outputs are linked to it and who reads those links. Cover the four association tables (`JobToOutputDatasetAssociation`, `JobToOutputLibraryDatasetAssociation`, `JobToOutputDatasetCollectionAssociation` on `Job.output_dataset_collection_instances`, and `JobToImplicitOutputDatasetCollectionAssociation` on `Job.output_dataset_collections`) and the writers: normal tool execution (`tools/actions/__init__.py`), the map-over path (`ExecutionTracker.record_success` in `tools/execute.py` calling `Job.add_output_dataset_collection` for every implicit HDCA on every element job, vs. collection outputs a job creates itself), job-cache copies (`copy_from_job`, `tools/actions/__init__.py` around the old-job loop), and model-store import. Tabulate the readers and what each assumes: the `/api/jobs/{id}/outputs` and `parameters_display` summaries (`services/jobs.py`, `managers/jobs.py` `summarize_job_outputs`), job access checks (`_user_can_access_job`), job search and cache reuse (`JobSearch`, `managers/collections.py` cached-output lookup), workflow extraction (`workflow/extract.py`), post-job actions (`job_execution/actions/post.py`), `Job.to_dict`/`update_output_states`, and `ImplicitCollectionJobs.output_dataset_collection_instances`. State how a reader tells "the job's own implicit map-over HDCA" (`HDCA.implicit_collection_jobs_id` equal to the job's `implicit_collection_jobs_association`) from an HDCA the job itself produced, and which readers already filter and which don't. Leave out ICJ model fields (see `Component - Collection Models`) and the job-cache matching rules (see `Component - Jobs API and Job Cache`).

## Why

#25004 shows the same implicit HDCA being listed as an output of every mapped job in `parameters_display`, and the sibling `/outputs` endpoint appears to have the same behavior. `Component - Jobs API and Job Cache` documents each read endpoint but not the write side, and `Component - Collection Models` lists the tables without their consumers; nothing says which readers depend on the over-broad association.
