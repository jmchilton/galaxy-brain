You'll be given a Galaxy issue (probably an issue number but maybe just a description of an issue).

Track down the root cause of the issue - try to reproduce if it makes sense - become confident with the issue. Sketch out possible fixes. 

Show root cause to user and offer options:

- Discuss further.
- Assign issue to user and post root cause summary.
- Assign issue to user - no post.
- Post root cause summary - do not assign to the user.
