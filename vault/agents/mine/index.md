# My Galaxy PRs and branches

## Overview

Tracks the user's open PRs and in-progress branches meant to become PRs, and moves them
toward merge: CI triage, undrafting, PR descriptions, and worktree cleanup.

## Files

- `AGENTS.md` — instructions for agents working here (`CLAUDE.md` symlinks to it).
- `MY_BRANCHES.md` — the categorized work queue of open PRs and branches.
- `PROJECT_MANAGEMENT.md` — worktree lifecycle and hand-off rules for implementation agents.
- `*_pr_description.md`, `*_notes.md`, etc. — per-branch working documents.
- `old/` — documents for merged PRs.
