# Issue File Docs

Default conventions for files in `repositories/<repo>/issues/<status>/<number>/`. A repository's own `issues/FILE_DOCS.md` replaces any section with the same pattern. Records may also hold other plans, questions, notes, and scripts.

## index.md

Ongoing debrief of the issue, without frontmatter. Links research and plans near the top. A `delegated/` issue says near the top to whom or what it was delegated, when, and where (plan comment, project).
