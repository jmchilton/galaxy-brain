# Foundry Issue File Docs

Foundry additions to [the default issue file docs](../../_defaults/issues/FILE_DOCS.md).

## issue_tags.md

Labels proposed by triage but not yet on GitHub: one backticked label per bullet, plus an optional `Parent: #N` line for a `roadmap/substep` issue. Each label may carry a short reason after it. The 🔖 Apply staged labels launcher applies them and removes the file.

## upstream_*.md

A proposed issue for an upstream repository the Foundry issue waits on, named `upstream_<project>_<shortname>.md` and drafted and reviewed per [TRIAGE_ISSUE.md](https://github.com/jmchilton/galaxy-brain/blob/main/vault/agents/wf_foundry/TRIAGE_ISSUE.md) step 6. Not posted until John asks.
