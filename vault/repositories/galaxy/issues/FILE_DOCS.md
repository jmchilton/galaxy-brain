# Galaxy Issue File Docs

Galaxy conventions for files in `repositories/galaxy/issues/<status>/<number>/`. Sections here replace the [default Issue File Docs](../../_defaults/issues/FILE_DOCS.md) with the same pattern; other files fall through to them.

Issues we filed carry the files from [PREPARE_TO_FILE](https://github.com/jmchilton/galaxy-brain/blob/main/vault/agents/gx_issues/PREPARE_TO_FILE.md), moved here from their `issues_incubator/` record once posted.

## raw.md

The source idea or file the issue was prepared from.

## proposal.md

The reviewed issue description, as proposed for posting.

## issue_tags.md

The labels recommended while preparing, applied when it was posted.

## debrief.md

Debrief of the research and rewrite behind the proposal.
