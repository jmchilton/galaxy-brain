Focused API test and all 17 parameter-validation unit tests pass; commit hooks (black, ruff, flake8, prettier, and repository checks) pass. The reporter's expression is separately incorrect — `column_names` is a list, so it should use membership such as `"MissCleavages" in value.metadata.column_names` — but a legitimate validator rejection must still produce a valid JSON 400.
