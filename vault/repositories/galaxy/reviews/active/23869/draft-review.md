I found two P2 regressions in the automatic Preview defaults:

**P2 — Keep specialized defaults from leaking to unrelated datatypes.** The new `rrd → rerunio` mapping (`lib/galaxy/config/sample/datatypes_conf.xml.sample:944–945`) also becomes the preference for `hep.root`, `bai`, and other unrelated binary formats. Likewise, `gwas_bgzip → locuszoom` makes ordinary `tar` datasets default to LocusZoom. The inheritance resolver compares qualified class-name strings, while dynamically created `subclass="true"` classes retain the generic parent's name. With the exact pinned plugins loaded, the actual datatype API handler returns these defaults on this branch and none on the exact parent; the plugins' datasource checks reject these inputs. Could we preserve actual datatype identity or otherwise constrain compatibility when inheriting these preferences, with a datatype-details regression covering the intended datatype and an unrelated sibling?

**P2 — Do not default compressed FASTA to the text-only alignment viewer.** Adding `alignment` to `fasta` (`lib/galaxy/config/sample/datatypes_conf.xml.sample:202`) also selects it for the generated `fasta.gz` and `fasta.bz2` types. The pinned viewer reads `/api/datasets/{id}/display` as FASTA text, but that endpoint returns the compressed bytes. In Chromium the real bundle renders an uncompressed alignment, while gzip and bzip2 versions of the same content both show `Error loading dataset: Cannot read properties of undefined (reading 'seq')` and an empty viewer. Could we keep this preference limited to uncompressed FASTA until the viewer supports decoding, and cover both compressed variants in a regression?

The 11 existing registry tests pass. I also verified all newly mapped IDs against the exact pinned packages. These tags control the default Preview, and multiple tags select only the last one, so the GeoJSON/FITS/NIfTI default choices should be deliberate. The change is readily reversible and does not migrate stored datasets, but the two confirmed Preview regressions should be fixed before approval.
