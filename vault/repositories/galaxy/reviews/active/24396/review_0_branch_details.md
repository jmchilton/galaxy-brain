`pr_24396_review_0` starts from the reviewed commit `770965bef62` and keeps every change small enough for a release branch. It renames the source dataclass to `ToolDataTableConfigSource`. It rejects managers built with both `config_sources` and `config_filename`, and moves the source-ordering logic out of the app into a tested `galaxy.tool_util.data` function. A reload failure after a registration is persisted is now reported through `error_message`, so it no longer aborts the install. Location-file directories outside the configured roots are watched non-recursively. Peers get a single reload task per registration. The in-place table swap is named, and the type asserts that couldn't fail are gone, along with the duplicated watcher setup. A new integration test checks the configured order end to end. Each behavior change has a test that fails without it. All PR-touched unit modules pass, and mypy is clean on the three touched library modules. Full unification of the two manager modes is left to the follow-up issue.
