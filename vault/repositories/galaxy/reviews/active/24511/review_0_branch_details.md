`pr_24511_review_0` sits on the reviewed commit `46102a0d363` (pushed to [jmchilton/galaxy](https://github.com/jmchilton/galaxy/tree/pr_24511_review_0)). It closes two charging gaps the review reproduced with red-to-green integration tests. Collection operation tools (filter, relabel, zip, ...) run on another user's public collection now charge the copies they make. A job-handler (late) cache hit in a map-over now charges only that job's own outputs. Before, it charged every element of the map-over's implicit collection, which overcharged cross-user and loaded N elements per job. The branch also reloads a purged history's HDAs by history id rather than one bound parameter per HDA, and drops a no-op `hda.purged` check in `HDAManager.copy`. The rest is test cleanup: a shared login helper, `DatasetPopulator.copy_dataset` and `recalculate_disk_usage`, and the second-copy dedupe check moved from an HDAManager unit test (now removed) into the integration test.
