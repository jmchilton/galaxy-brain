Branch `pr_24770_round_0_rev_0` (from reviewed head `8ec2452c3bb`) tightens the readiness-snapshot mechanism without changing its design. The snapshot query now lives once in `galaxy.model.dataset_collections.readiness`, and the monitor calls it. Snapshots treat all non-ready states as one value, so a blocker moving queued → running no longer replays the invocation. Pick-value (`require_ready`) connection waits now record snapshots too, so a paused input stops replaying every pass. The collection blocker search requires `states` and has typed input, and `galaxy.exceptions` (galaxy-util) no longer imports `galaxy.workflow`. Tests now cover snapshot wakes on deletion, missing rows and batching, prove that the running member (not the errored one) wakes the auto-extension wait, and cover the element/adapter branches. HDA-column wake assertions are isolated from the history-audit trigger. All edited test files pass: `test_scheduling_manager.py` (15), `test_workflow_progress.py` (14), `test_input_readiness.py` (10). Each new test was red-checked against a deliberately broken implementation.
