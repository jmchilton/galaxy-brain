# Unposted draft — request changes

The model-store reuse and integration tests are good foundations. I verified the dataset and paired-collection round trips, including contents, types, genome builds and tags. Two issues look worth fixing before merging:

**P2 — Forward `discarded_data` to the background import** (`lib/galaxy/webapps/galaxy/services/history_contents.py:619–625`). The new endpoint accepts `CreateHistoryContentFromStore`, but drops this field when building `ImportModelStoreTaskRequest`; the worker always uses the `FORBID` default. Importing the same archive through the synchronous and asynchronous endpoints showed that `allow` keeps a missing-data HDA non-deleted synchronously but deletes it asynchronously, while `force` creates a discarded HDA synchronously but imports its bytes as `ok` asynchronously. The documented default is also `allow`. Could we carry and convert this option through the task request, with an async integration test? The new UI's explicit `forbid` request already matches the current worker behavior.

**P2 — Continue tracking export failures after the dialog closes** (`client/src/components/History/Content/ExportToAnotherGalaxyDialog.vue:96–101`). Closing the dialog stops the Celery task monitor, leaving Recent Exports with only the storage request ID. Storage is finalized on failure too, so a later failed export appears READY and offers a broken link. I reproduced this by delaying a FAILURE response, closing the real dialog, and then checking through the real persistent storage monitor. Could we retain task-outcome tracking independently of the open dialog, or retain the Celery task ID for Recent Exports to check? A close-before-failure test would cover the missing case.

Validation: 54 model-store tests passed (1 expected failure), both round-trip integration tests and both new API tests passed, and 51 client tests passed. The new API and persisted imports are the main compatibility commitments; imported copies can be deleted and recreated, while the dialog correctly discloses the export link's temporary access and lack of withdrawal.
