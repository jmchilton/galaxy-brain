## Risks

The physical layout change and removed metadata API field are one-way compatibility decisions. Root-only reads intentionally stop supporting old wrapped stores/history imports; please explicitly settle that tradeoff and the recovery path for existing histories. The local tests cover the new layout, but do not prove remote object-store cache eviction or Pulsar staging. When combining #23966, listed wrapped stores also need normalization before materialization persistence/metadata.
