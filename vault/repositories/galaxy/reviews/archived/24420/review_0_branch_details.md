`pr_24420_review_0` is branched from the reviewed commit `8faff364290`. It moves the `exact` check out of the legacy controller. The id/version predicate is now `AbstractToolBox.is_exact_tool`, and `ToolsService._get_tool(..., exact=)` enforces it after the access check and before materialization. The predicate accepts a short (old) id or a versionless guid as well as the full guid, so `exact=true` no longer 404s for installed shed tools requested by short id. Toolbox unit tests on guid fixtures cover this. The API test now asserts the 404 message and the no-version path, and the duplicated fallback check is dropped.
