`pr_24517_review_0` builds on the PR head (`ad4429e1`). It makes boto3's `get_data_head` raise `ObjectNotFound` for a missing key instead of leaking botocore's `ClientError`, so all backends raise the same exception. It also returns `b""` for a non-positive size instead of sending S3 the invalid `Range: bytes=0--1`. On the test side, it moves the cached-copy fallback tests onto Pithos, a store that really cannot stream, and imports `ClientError` at module top. It adds a SeaweedFS integration test that runs `get_data_head` against real boto3 and cloud stores, covering a stale empty cache copy, an empty object and a missing object.
