Risks are minimal - this change doesn't lock Galaxy into particular difficult to change choices (a two-way door). It adds one unconditional full clear of the per-process `to_dict` and curated/EDAM caches at the end of `CachedToolBox.invalidate_index_cache`, plus a unit test; reverting is a two-line change. The only cost to weigh is that every index invalidation broadcast (each populate) now drops all cached tool payloads, so the next panel/tool-list request in each process rebuilds them from stubs, without parsing tools.
