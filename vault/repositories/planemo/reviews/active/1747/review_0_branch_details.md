Review branch `pr_1747_review_0` is cut from the reviewed commit `0fe5ce4b`. Its main fix is to `updated_tools`, which now counts tool ids per step instead of comparing deduplicated sets. An upgrade to a version that another step already uses is now reported, where before the CLI threw it away. The branch also moves the latest-revision selection into a pure `find_updated_tool_id(tool_id, repos)`, so its tests no longer monkeypatch the Tool Shed lookup; one end-to-end `outdated_tools` test keeps that monkeypatch to cover the result dict. It adds mutation-checked cases for the no-downgrade seed, the malicious filter and numeric revision ordering, plus a gxformat2-original case for `updated_tools`. It renames the CLI locals that shadowed the module functions, and asserts the `->` changelog lines in the Galaxy-gated workflow test, which was not run locally.
